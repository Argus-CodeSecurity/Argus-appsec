Add a scan

Upload a report

Generate a JSON report and upload it:

nephilex scan . -f json -o report.json

Or send it straight from the CLI

Pipe a scan directly into the dashboard (handy for CI):

nephilex scan . -f json | curl -s -X POST --data-binary @- \
  -H "Content-Type: application/json" \
  http://127.0.0.1:8000/api/scans

The JSON content type is required. If the dashboard runs with NEPHILEX_DASHBOARD_TOKEN, also pass -H "Authorization: Bearer $NEPHILEX_DASHBOARD_TOKEN".
